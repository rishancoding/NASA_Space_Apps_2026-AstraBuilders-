Local font assets used by the light UI:

- EB Garamond: page titles, inspired by Cluely. Source: https://github.com/google/fonts/tree/main/ofl/ebgaramond. See EB-Garamond-LICENSE.txt.
- Geist Sans: navigation, inspired by Cluely. Source: https://github.com/vercel/geist-font. See Geist-LICENSE.txt.
- Inter: controls, navigation, body copy, and charts. Source: https://github.com/rsms/inter. See Inter-LICENSE.txt.

All fonts use the SIL Open Font License 1.1. The browser loads these bundled files without contacting a font CDN. Inter body type and tight spacing reference Heyclicky's website.
