Local font assets used by the light UI:

- Geist Sans: homepage and page titles. Source: https://github.com/vercel/geist-font. See Geist-LICENSE.txt.
- Inter: controls, navigation, body copy, and charts. Source: https://github.com/rsms/inter. See Inter-LICENSE.txt.

Both fonts use the SIL Open Font License 1.1. The browser loads these bundled files without contacting a font CDN.
