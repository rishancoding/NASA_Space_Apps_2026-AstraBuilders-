# Reviewed labels belong here

Copy `../clean/label_review_queue.csv` here before editing it. Generated files in
`data/clean/` are replaced on rebuild. This directory is for the model team's
reviewed, version-controlled annotations and target-definition notes.

Define the target, identify the conditions at which it was observed and record
the reviewer and source locator. Do not turn "extinguished" into "never burned"
or a failed igniter into a material flammability result. See
[DATA_HANDOFF.md](../DATA_HANDOFF.md) for the training handoff. The current data
builder does not apply labels or train a model; that is the subsequent step.
